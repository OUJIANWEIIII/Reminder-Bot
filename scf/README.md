# 腾讯云 SCF 下班打卡提醒

这是比 GitHub Actions 更适合准时提醒的部署方案。腾讯云 SCF 定时触发器会在指定时间触发云函数，Webhook 地址通过环境变量 `WECHAT_WEBHOOK_URL` 读取，不写进代码。

## 创建云函数

1. 打开腾讯云控制台，进入「云函数 SCF」。
2. 新建函数，选择「从头开始」。
3. 函数名建议填写 `wechat-clock-out-reminder`。
4. 运行环境选择 Node.js 16 或 Node.js 18。
5. 执行方法填写：

```text
index.main
```

6. 复制 `index.js` 的内容到云函数代码编辑器。

## 配置环境变量

在云函数配置里添加环境变量：

```text
WECHAT_WEBHOOK_URL=你的企业微信群机器人 Webhook
```

不要把 Webhook 写到代码里，也不要提交到仓库。

## 配置定时触发器

腾讯云 SCF 定时触发器使用 7 字段 Cron 表达式：秒、分钟、小时、日、月、星期、年。官方文档示例里 `0 15 10 ? * MON-FRI *` 表示周一到周五上午 10:15 触发。

周一到周六每天 18:05 的表达式：

```text
0 5 18 ? * MON-SAT *
```

配置步骤：

1. 进入函数详情。
2. 打开「触发管理」或「触发方式」。
3. 添加触发器。
4. 类型选择「定时触发器」。
5. 触发器名称填写 `ClockOutReminder1805`。
6. Cron 表达式填写：

```text
0 5 18 ? * MON-SAT *
```

7. 保存。

函数代码里还有一层北京时间保护：只有周一到周六北京时间 18:00-18:20 之间才会发送。这样即使误触发，也不会在早上或半夜发消息。

## 手动测试

在云函数控制台点击「测试」，事件内容填：

```json
{
  "test": true
}
```

如果环境变量正确，企业微信群会收到：

```text
下班打卡提醒：别忘了打卡下班。
```
